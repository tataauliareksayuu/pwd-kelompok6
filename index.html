Apa yang Dipelajari?

HTML

HTML adalah singkatan dari HyperText Markup Language.

PHP

Memproses data, mengelola database, dan membuat fitur website menjadi lebih interaktif.

CSS

CSS adalah sebuah dokumen yang berdiri sendiri dan dapat dimasukkan dalam kode HTML atau sekedar mejadi rujukan oleh HTML dalam pendefinisian style.

JavaScript

JavaScript adalah bahasa pemrograman yang dipakai untuk membuat website lebih dinamis dan interaktif.
