Materi Dasar

Kenali beberapa dasar pemrograman untuk pemula.

01. HTML

HTML digunakan untuk membuat struktur halaman website, seperti judul, paragraf, gambar, dan tombol. 

<h1>Halo Dunia!</h1>

02. CSS

CSS digunakan untuk mengatur tampilan website, seperti warna, ukuran, jarak, dan posisi elemen. 

h1 {
    color: purple;
}

03. JavaScript

JavaScript digunakan untuk membuat halaman website dapat memberikan respon terhadap tindakan pengguna. 

alert("Halo!");
